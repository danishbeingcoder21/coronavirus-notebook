#  COVID-19 Data Analysis Using Python

##  Project Overview

This project focuses on analyzing COVID-19 data across different countries using Python. The objective is to explore infection rates, mortality statistics, and country-wise trends through data analysis and visualization.

The project demonstrates how raw datasets can be processed, analyzed, and transformed into meaningful visual insights.

##  Technologies Used

- **Python** – Programming language
- **Pandas** – Data cleaning, manipulation, and analysis
- **Seaborn** – Statistical data visualization
- **Matplotlib** – Creating and customizing graphs
- **Jupyter Notebook** – Development environment

##  Dataset Information

The dataset contains 225 rows and 10 columns, including:

- Country
- ISO Code
- Population
- Continent
- Total Cases
- Total Deaths
- Cases per Million Population
- Deaths per Million Population
- Death Percentage

## Key Features and Analysis

**1. Data Exploration**
- Displayed dataset dimensions and structure.
- Examined the first and last five records.
- Identified missing values.
- Replaced missing values using Pandas.
- Generated descriptive statistical summaries.

**2. Country-Wise COVID-19 Analysis**
- Identified the five countries with the highest and lowest COVID-19 cases.
- Compared countries with the highest and lowest total deaths.
- Analyzed countries with the highest and lowest death percentages.

**3. Data Visualization**
- Bar charts comparing COVID-19 cases across countries.
- Bar charts representing total deaths.
- Death percentage comparison charts.
- Scatter plot showing the relationship between total cases and total deaths.
- Correlation heatmap displaying relationships between numerical variables.

##  Skills Demonstrated

- Data Visualization
- Data Manipulation using Pandas
- Correlation Analysis

##  How to Run

1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

```bash
pip install pandas seaborn matplotlib notebook
```

4. Open `CORONAVIRUS.ipynb` in Jupyter Notebook.
5. Update the CSV dataset path in the notebook to match your local file location.
6. Run the notebook cells sequentially to view the analysis and visualizations.
